Calculadora de Consumo de Energia ⚡

Esta calculadora foi desenvolvida para ajudar usuários a estimar o consumo de energia elétrica de aparelhos eletrônicos e entender melhor o impacto desses equipamentos na conta de luz.

A ferramenta permite inserir informações como:

Potência do aparelho (em watts)

Quantidade de horas de uso por dia

Número de dias de uso no mês

Valor do kWh cobrado pela companhia de energia

Com base nesses dados, a calculadora realiza automaticamente os cálculos e apresenta:

Consumo diário de energia

Consumo mensal estimado

Custo aproximado na conta de luz

Objetivo do projeto

O objetivo deste projeto é facilitar a conscientização sobre o consumo de energia, ajudando pessoas a identificar quais aparelhos consomem mais eletricidade e como pequenas mudanças de uso podem reduzir gastos.

Além disso, o projeto serve como um exemplo educacional de lógica de programação e cálculos matemáticos aplicados, podendo ser utilizado para estudo, prática ou como base para projetos maiores.

Como usar

Insira a potência do aparelho em watts (W).

Informe quantas horas por dia o equipamento é utilizado.

Defina quantos dias no mês ele é usado.

Digite o valor do kWh da sua região.

A calculadora exibirá automaticamente o consumo e o custo estimado.
